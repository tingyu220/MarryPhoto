# UI 设计契约 · 婚礼数字影集

> 本文档回答一个问题：**什么样的界面，才不会毁掉这批照片。**
> 所有页面与组件的实现以此为准；与本文冲突的视觉决定一律以本文为准。

---

## 1. UI Brief

| 项 | 结论 |
| --- | --- |
| 产品类型 | 私人纪念影集（叙事型网站 / portfolio，**不是**工具、不是后台） |
| 主要用户 | 姐姐与姐夫；其次父母家人；多数从**微信**里点开 |
| 主任务 | **看照片**。唯一的核心动作就是"看下一张" |
| 次要任务 | 理解这一天发生了什么；找到某张照片；最后读到那封信 |
| 语气 | 安静、克制、温暖、私人。像一本印刷出来的画册，不像一个网站 |
| 信息密度 | **极低**。屏幕的 80% 以上应该被照片和留白占据 |
| 层级模型 | 照片 → 留白 → 文字 → UI（UI 永远最弱） |
| 导航模型 | 顶部极简文字导航（滚动隐藏/上滚出现）+ 页脚；首页第一屏无导航 |
| 响应式目标 | 375 / 414 / 768 / 1024 / 1440，**移动优先** |
| 无障碍 | 键盘可达、焦点可见、对比度达 AA、尊重 `prefers-reduced-motion` |
| 必须避免 | 后台感、婚庆模板感、卡片三件套、廉价动画 |

**一句话检验标准**：把任何一页截图发给一个不认识这个项目的人，
如果他说"这是不是一个婚庆公司的网站"，就是失败的。

## 2. 参考方向

### 2.1 方法依据（已完整阅读，作为本文档的推导基础）

- `designing-frontend-ui` skill 的 `references/design-principles.md`
  → 学到：先确定页面主决策再谈风格；用语义 token 而不是散落的魔法值；
  用层级（大小、字重、间距、对齐）而不是装饰（渐变、玻璃、发光）制造对比；
  明确列出"泛化的 AI 风格"并避免；响应式不是等比缩放，而是重新决定什么堆叠、什么收起。
- `references/landing-page-design.md`
  → 学到：Hero 用**一个**主视觉去证明内容本身（照片就是产品本身），
  不做空洞装饰；区段之间交替密度、对齐、媒体形态与尺度，避免单调的卡片网格；
  移动端要保证信息顺序与行动可达，媒体要有意裁切而不是缩小。

### 2.2 参考方向（**检索入口，尚未逐站核对**；实施 Wave 2/3 前由总控实际打开并提炼）

- 摄影机构与画册型作品集（Magnum Photos、Aperture 的线上影集）——学"编辑节奏"：
  大图与小图的交替、章节间的大片留白、标题只用两种字号。
- 报纸/杂志的年度图片专题——学"图注与时间"的处理：极小字号、低对比度、
  永远不抢图，但信息完整。
- refero.design 的 editorial 风格样本集合（`styles.refero.design`）——检索入口。
- 35mm 胶片摄影作品集（Film 模式的直接参考）——学"一屏一张 + 编号 + 时间"的信息排布。

> 规则：**提取可迁移的原则（层级、构图、交互、动效、组件解剖），不复制某一个作品。**
> 不得在没有实际打开的情况下声称参考了某个站点。

## 3. 设计 Token

唯一来源：`src/styles/tokens.scss`。任何组件里不允许出现未在此定义的色值/时长/间距。

~~~scss
:root {
  /* ---- 颜色：纸与墨 ---- */
  --c-bg:          #F5F2EC;   /* 暖白纸面，全站底色 */
  --c-bg-sunk:     #EDE9E1;   /* 极浅的下沉区（页脚、分隔） */
  --c-ink:         #151515;   /* 正文与标题 */
  --c-ink-soft:    #3A3A3A;   /* 次级文字 */
  --c-muted:       #777777;   /* 图注、时间、序号 */
  --c-faint:       #A8A29A;   /* 序号水印、占位 */
  --c-line:        rgba(21,21,21,0.12);
  --c-accent:      #6E2B2B;   /* 深酒红：下划线、签名，全站面积 <1% */
  --c-warm:        #8A6A4F;   /* 暖棕：hover 文字、小标记 */

  /* ---- 观看态（Lightbox）---- */
  --c-veil:        #0B0B0B;   /* 全屏看图的底：接近黑，照片最舒服 */
  --c-veil-ink:    #EDEAE4;
  --c-veil-muted:  rgba(237,234,228,0.55);

  /* ---- 字体 ---- */
  --f-display: "Cormorant Garamond", "Songti SC", "Noto Serif CJK SC", serif;
  --f-serif:   "Songti SC", "Noto Serif CJK SC", "Source Han Serif SC", "SimSun", serif;
  --f-sans:    -apple-system, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
  --f-mono:    "SF Mono", ui-monospace, Menlo, Consolas, monospace;

  /* ---- 字号（移动端为基准，桌面端用 clamp 放大）---- */
  --t-display: clamp(2.25rem, 9vw, 5.5rem);
  --t-h1:      clamp(1.75rem, 5vw, 2.75rem);
  --t-h2:      clamp(1.25rem, 3.2vw, 1.75rem);
  --t-body:    1rem;
  --t-small:   0.875rem;
  --t-caption: 0.75rem;
  --t-label:   0.6875rem;   /* 全大写字母标签 */

  /* ---- 字距 ---- */
  --ls-display: 0.16em;     /* OUR DAY */
  --ls-label:   0.14em;     /* 001 / 08:23 / SCENE 标签 */
  --ls-body:    0.01em;

  /* ---- 行高 ---- */
  --lh-tight: 1.15;
  --lh-body:  1.75;
  --lh-letter: 1.95;        /* 信纸专用 */

  /* ---- 间距：8 基准 ---- */
  --s-1: 4px;  --s-2: 8px;  --s-3: 12px; --s-4: 16px;
  --s-6: 24px; --s-8: 32px; --s-12: 48px; --s-16: 64px;
  --s-24: 96px; --s-32: 128px; --s-48: 192px;

  /* ---- 版心 ---- */
  --w-text:   34rem;   /* 正文/信纸 */
  --w-page:   72rem;   /* 普通页面 */
  --w-wide:   96rem;   /* 全宽影集 */
  --pad-x:    clamp(20px, 5vw, 64px);

  /* ---- 形状 ---- */
  --r: 0;              /* 全站零圆角，唯一例外是圆形人物头像 */

  /* ---- 层级 ---- */
  --z-nav: 50; --z-veil: 100;

  /* ---- 动效 ---- */
  --e-out:   cubic-bezier(0.22, 0.61, 0.36, 1);
  --d-fast:  200ms;
  --d-base:  400ms;
  --d-slow:  600ms;
  --d-breathe: 20s;    /* 首页第一屏的极缓慢缩放 */

~~~

**没有阴影 token，因为全站不使用阴影。** 如果某个组件"需要一点阴影才好看"，
说明它的层级关系没有用间距和留白表达清楚，应当重做而不是加阴影。

## 4. 排版规范

### 4.1 中西混排

- **拉丁文字用衬线体（Cormorant Garamond）**，中文正文用系统衬线（宋体系）。
- 中文与拉丁/数字之间**不手动加空格**，由 `text-spacing-trim` 与字体天然间距处理；
  时间、编号等纯数字使用等宽字体（`--f-mono`）以保证对齐不跳动。
- 中文标点使用全角；引号使用「」而不是 ""（更安静，更适合中文）。
- 标题不使用全角空格排版，靠 `letter-spacing` 控制。

### 4.2 角色对照

| 角色 | 字体 | 字号 | 字距 | 行高 | 颜色 |
| --- | --- | --- | --- | --- | --- |
| 首屏大标题 OUR DAY | display | `--t-display` | `--ls-display` | 1.0 | `--c-ink` |
| 页面标题 | display | `--t-h1` | 0.06em | 1.15 | ink |
| 章节标题 | serif | `--t-h2` | 0.02em | 1.3 | ink |
| 正文 | serif | `--t-body` | `--ls-body` | 1.75 | ink-soft |
| 图注 / 描述 | serif | `--t-small` | 0 | 1.6 | muted |
| 时间 / 编号 / 计数 | mono | `--t-label` | `--ls-label` | 1.2 | muted |
| 导航项 | sans | `--t-small` | 0.05em | 1 | ink / muted |

### 4.3 字体加载策略（性能红线）

**绝不加载全量 CJK 网络字体。** 一套完整的思源宋体/霞鹜文楷是 5～15MB，
会让微信首屏直接崩掉。

| 用途 | 方案 |
| --- | --- |
| 拉丁标题 | 自托管 **子集化** 的 Cormorant Garamond（仅 latin + 数字 + 标点），woff2，约 40KB |
| 中文正文 | **系统字体**：Songti SC / Noto Serif CJK SC / SimSun，不下载任何字节 |
| 中文标题 | 同上（系统宋体已经足够好看） |
| 信件页（可选） | 霞鹜文楷 Screen 通过 `unicode-range` 分片 CDN 按需加载，`font-display: swap`；**若拖慢首屏则直接放弃，退回系统宋体** |
| 数字/编号 | 系统等宽字体 |

字号必须使用 `rem`（尊重用户浏览器设置），不用 `px` 定用户可见文字。

## 5. 布局原则

1. **留白即设计**：章节之间默认 `--s-24`～`--s-32`（96～128px）的垂直留白。
   常规网站用 60px，我们用两倍。
2. **不用卡片**：照片直接贴在纸面上，不加边框、不加圆角、不加阴影。
   如果两张照片需要分组，用**更近的间距**分组，而不是画一个框。
3. **图片比例**：
   - 全屏图：`object-fit: cover`，焦点由 `object-position` 控制（overrides 可指定焦点）；
   - 列表图：保持原始比例（瀑布流的前提）；
   - 联系表：1:1 强制裁切（找图优先，不追求好看）。
4. **网格**：桌面 12 列，移动 4 列。全宽影集使用 `--w-wide`，正文使用 `--w-text`。
5. **交错节奏**：Featured 与 Story 中，相邻三张图的"尺寸 + 对齐 + 留白"不能重复。
   允许一张图只占 4 列并靠左，下一张占 8 列靠右。
6. **一屏一件事**：每个视口内只有一个视觉重心。

## 6. 组件规范

### 6.1 顶部导航 SiteHeader

- 纯文字，字号 `--t-small`，间距大（`--s-8` 以上），小写英文或中文均可。
- 无背景色块、无边框、无 logo 图标。滚动后可以是 `backdrop-filter: blur(8px)` +
  半透明纸色（**这是全站唯一允许的模糊**）。
- 当前页用 `--c-accent` 的 1px 下划线表示，不加粗、不变色。
- 滚动向下隐藏、向上出现，transition 用 `--d-fast`。
- **首页第一屏不显示**，滚动超过 100vh 后淡入。

### 6.2 按钮

全站按钮只有两种：

1. **文字按钮 + 箭头**：`View Memories →`，颜色 ink，hover 时箭头右移 4px。
2. **下划线文字按钮**：筛选、切换模式，选中态是 1px 下划线（accent 色）。

**没有填充按钮、没有彩色按钮、没有描边按钮、没有图标按钮。**
唯一例外：Viewer 的关闭/翻页热区（无可见样式，只有热区）。

### 6.3 缩略图 PhotoThumb 的状态

| 状态 | 表现 |
| --- | --- |
| 未加载 | 主色（`photo.color`）纯色块，尺寸由 `aspect-ratio` 撑开 |
| 加载中 | blur 占位图，轻微 `filter: blur(12px)` |
| 加载完成 | 300ms opacity 0→1，blur 0 |
| 失败 | 同色块 + 极小号 mono 的 ID，**不显示破图图标** |
| hover（仅桌面） | 桌面网格中最多 1.02 倍缩放，或无变化；不在移动端启用 |

### 6.4 筛选与视图切换

- 一行文字，用 `·` 分隔；选中项加下划线并变为 ink 色，未选中为 muted。
- 移动端允许横向滚动，**不使用下拉框**（下拉框立刻带来后台感）。
- 切换视图（瀑布流/联系表/胶片/时间线）使用同样样式的文字切换。

### 6.5 全屏查看器 PhotoViewer

- 底色 `--c-veil`（近黑）。
- UI 元素：右上 `23 / 386`（mono，`--c-veil-muted`）；
  底部一行：时间 · 描述（`Photo` 类型里没有地点字段，不做地点），**最多一行，超出省略**。
- 打开后 3 秒无操作，UI 自动淡出；鼠标移动/触摸后淡入。
- 禁止出现：分享、下载、收藏、点赞、幻灯片按钮、缩略图条（V1 不做）。

### 6.6 页脚

三行以内：站名 · 日期 · 一句极短的话（如「2026.10.18 · 这一天」）。
无社交链接、无版权声明长文、无技术栈水印。

## 7. 动效规范

| 场景 | 变化 | 时长 | 缓动 |
| --- | --- | --- | --- |
| 页面进入 | opacity 0→1 | `--d-base` | `--e-out` |
| 元素随滚动出现 | opacity 0→1 + translateY(12px→0) | `--d-slow` | `--e-out` |
| 列表错开 | 每项延迟 60～80ms，**同屏最多错开 6 项** | — | — |
| 首页第一屏 | opacity 0→1，之后极缓慢 scale 1→1.04 | 600ms / 20s | linear |
| 图片加载完成 | opacity 0→1 + blur 12px→0 | 300ms | `--e-out` |
| hover | 颜色或位移 ≤4px | `--d-fast` | `--e-out` |

**禁止**：bounce/elastic 缓动、爱心、花瓣、粒子、视差、满屏同时入场、
超过 600ms 的等待动画、滚动劫持（scroll hijacking）。

**必须**：`@media (prefers-reduced-motion: reduce)` 下把所有动效降为
"直接显示"（时长归零、位移归零），且不影响任何信息可达性。

## 8. 响应式断点

| 断点 | 变化 |
| --- | --- |
| < 768px | Gallery 2 列；Contact 3 列；Featured 单列大图；首屏文字缩小；导航收为一行可横滑 |
| 768–1279 | Gallery 3 列；Contact 5 列；导航展开；Featured 双列错落 |
| ≥ 1280 | Gallery 4 列；Contact 6 列；版心 `--w-page` / 全宽影集 `--w-wide` |

> 断点口径以**实现**为准（与 docs/01 §7.4 / §7.5 一致）：Contact Sheet 只有 3 / 5 / 6 三档，
> 没有 480–767 的"4 列"中间档 —— 那一档可用宽度太小，四列会把单格压到 100px 以下。
| ≥ 1440 | 全宽影集用 `--w-wide`，左右留白不再增大，避免照片被拉散 |

原则：**不是等比缩小，而是重新决定什么堆叠、什么收起、什么改变优先级。**
移动端信息顺序必须与桌面端一致（照片 → 图注 → 时间）。

## 9. 无障碍与状态

- 所有可点元素必须是 `<button>` 或 `<a>`，有可见的 `:focus-visible` 轮廓
  （1px accent 色 + 2px offset，不用浏览器默认蓝框）。
- 照片 `alt` 优先用 `description`；无描述时用「时间 + 场景」自动生成，
  **不允许出现空 alt**。
- 正文对比度 ≥ 4.5:1（`--c-muted` #777 在 #F5F2EC 上约 4.6:1，刚好达标；
  更小的字要用 `--c-ink-soft`）。
- 必须实现的非理想状态：
  | 状态 | 表现 |
  | --- | --- |
  | 加载中 | 主色块 + 极简骨架，不用转圈 spinner |
  | 空结果（筛选后无照片） | 一行字「这一类别还没有照片」+ 返回全部 |
  | 单张照片 | 不显示计数、不显示翻页 |
  | 图片加载失败 | 色块 + ID，不显示破图 |
  | 没有 overrides 描述 | 显示时间，不显示"暂无描述" |

## 10. 反模式清单（出现任何一条即判不合格）

- ❌ 每一组内容都套一个卡片（白底 + 圆角 + 阴影）
- ❌ 彩色胶囊标签 / 徽章（"精选" "家人" 用小色块标出来）
- ❌ 三列特性网格（图标 + 标题 + 两行说明）
- ❌ 渐变、发光、玻璃拟态（导航栏的轻微模糊是唯一例外）
- ❌ 大量图标（相机、爱心、日历、定位…）
- ❌ 轮播图 / 自动播放幻灯片
- ❌ 满屏飘落花瓣、爱心、粒子
- ❌ 每个元素都做入场动画
- ❌ 大圆角（> 4px）
- ❌ 字号超过 5 个层级的"设计系统展示"
- ❌ 深色主题皮肤切换（本项目只有纸色 + 观看黑两种环境）
- ❌ 页脚出现技术栈、版权长文、社交图标
