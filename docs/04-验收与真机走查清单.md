# 验收与真机走查清单

> 这份清单是 Wave 4 的执行手册。
> **为什么必须真机走查**：本项目的自动检查（`npm run render-check`）只能验证"渲染出的 DOM 与样式"。
> 手势、滚动、IntersectionObserver、hover、键盘焦点这些**只有真实浏览器才会执行**。
> 自动检查全绿 ≠ 体验没问题。

---

## 0. 跑之前先做三件事

~~~bash
npm run typecheck      # 类型闸门
npm run render-check   # 无浏览器渲染检查（当前 263+ 项）
npm run build          # 生产构建
npm run budget         # 性能预算（读 dist/ 实测）
~~~

四项全绿再开始走查。任何一项红了先修，不要在红的基线上走查。

---

## 1. 走查顺序（由重到轻，发现前一层的问题就先停下修）

1. **坏的**：布局断裂、裁切、横向滚动条、内容缺失、控制台报错
2. **主任务**：照片是不是第一眼看到的东西；信息层级对不对
3. **排版与间距**：字号、行高、对齐、密度、token 是否一致
4. **状态**：加载中 / 空 / 失败 / 单张 / 超长内容
5. **可达性**：键盘能不能走完、焦点看不看得见、对比度、减弱动态效果
6. **动效**：时长是否舒服、有没有分散注意力、有没有卡顿
7. **装饰性打磨**（最后才做）

> 顺序不能颠倒：界面坏了的时候，讨论"圆角好不好看"是浪费。

---

## 2. 必须覆盖的视口

| 视口 | 怎么得到 | 看什么 |
| --- | --- | --- |
| **375 × 812** | 浏览器设备模拟 / 真机 iPhone | 主力场景，微信里打开就是这个宽度 |
| **414 × 896** | 同上 | 大屏手机 |
| **1440 × 900** | 桌面 | 版心、留白、多列 |
| **768** | 平板 | 断点切换处最容易出问题 |

**禁止只在一个宽度上看。** 响应式要"实际看"，不能靠推断。

## 3. 逐页清单

### 首页 `/`
- [ ] 首屏是一张全屏照片，**不是轮播**；文字在照片上清晰可读
- [ ] OUR DAY / 姐姐 & 姐夫 / 日期 / Explore ↓ 四行都在，且手机上没有挤在一起
- [ ] 20 秒极缓慢呼吸缩放能看出来，但**不觉得晕**
- [ ] 向下滚动时首屏文字淡出（淡到约 15% 就不再淡），不出现突然变空的黑屏
- [ ] 承诺文案三行、精选横滑（能左右滑、能点开大图）、三个入口、最后的信
- [ ] 第一屏**没有导航栏**；滚过一屏后导航淡入
- [ ] iOS 上首屏高度不因地址栏跳动而抖动（用的是 `dvh`）

### 精选 `/featured`
- [ ] 版面是**交替**的：全幅 / 双列错落 / 单张居中 / 一大一小 / 错落，不是统一网格
- [ ] 每 3 块出现一行小字（时间 · 场景），起到呼吸作用
- [ ] 点击任意一张都能打开大图，**打开的就是点的那张**
- [ ] 双列在手机上变成单列，不错位

### 这一天 `/story`
- [ ] 8 个章节顺序正确：清晨 → 化妆 → 准备出门 → 接亲 → 到达酒店 → 仪式 → 合照 → 晚宴
- [ ] 每章有大号时间、标题、一句话、3~10 张照片
- [ ] 左侧细竖线随滚动生长（如果做了），手机上不碍事
- [ ] 某一章没有照片时，只有文字，**不出现破图或空框**

### 全部照片 `/gallery`
- [ ] 默认是瀑布流，横竖图自然混排，**没有横向滚动条**
- [ ] 筛选（全部/婚礼/家人/朋友/抓拍/现场/细节）点了之后张数变化正确
- [ ] 四种模式切换：瀑布流 / 联系表 / 胶片 / 时间线，**切换后筛选条件保留**
- [ ] 切换模式**不重置滚动位置**、不整页闪烁
- [ ] 浏览器后退键能回到上一个筛选状态（筛选写进了 URL）
- [ ] 滚到底部过程中，**没有加载几百张高清图**（见第 5 节）

### 联系表 `/gallery?view=contact`
- [ ] 序号是 001 / 002 / 003 补零三位，且**序号与查看器顶部 "23 / 386" 指向同一张**
- [ ] 悬停时轻微放大（仅桌面），手机上没有奇怪的效果
- [ ] 375px 下单格宽度 ≈ 109px，不挤

### 胶片 `/gallery?view=film`
- [ ] 一屏一张，慢慢看，**不是幻灯片自动播放**
- [ ] 下方信息：编号 · 时间 / 描述，两行封顶
- [ ] 空格 / ↓ 下一张、↑ 上一张；**在第一张按 ↑ 不会把页面卡住**
- [ ] 描述缺失时不留空行

### 时间线 `/gallery?view=timeline`
- [ ] 按小时分组，组头是时间点，组尾是"N 张"
- [ ] 超过 6 张的组有"+N"入口，**点开、收起都正常**
- [ ] 折叠时点第 7 张，打开的仍然是第 7 张（不是第 1 张）
- [ ] 没有时间的照片落在最后「时间未知」组，**没有被丢掉**

### 人物 `/people`
- [ ] 一列条目，圆形头像 + 姓名 + 张数；张数为 0 的人不出现
- [ ] 点某个人 → 跳到 `/gallery?p=xxx` 且**只显示这个人的照片**

### 瞬间 `/moments`
- [ ] 比 Gallery 更慢、更大、更少；每张配一行时间/描述
- [ ] 空的时候只有一行安静的文字

### 写给姐姐 `/letter`
- [ ] 窄栏、大行高，读起来像信纸
- [ ] 小照片略微旋转、有白边，**没有阴影**
- [ ] 除了信、照片、签名，没有多余元素
- [ ] 从首页走到这里，情绪上是"终点"而不是"又一个标签页"

### 全屏查看器（所有页面共享）
- [ ] **PC**：← → 切换、ESC 关闭、滚轮缩放、双击放大
- [ ] **手机**：左右滑动、双指缩放、**下滑关闭**、轻触隐藏/显示 UI
- [ ] 右上角计数正确；底部时间/描述只占一行、超长省略
- [ ] 3 秒无操作 UI 自动淡出，动一下鼠标/触摸又出现
- [ ] 关闭后**焦点回到刚才点的那张缩略图**（键盘用户）
- [ ] 屏幕上**没有**分享/下载/收藏/点赞/幻灯片/缩略图条
- [ ] 沉浸：底色接近黑，照片是唯一的亮的东西

## 4. 状态清单（没人愿意做，但必须做）

| 状态 | 怎么造 | 期望 |
| --- | --- | --- |
| 加载中 | 网络面板调成 Slow 3G | 主色块 → 模糊图 → 清晰，**不出现破图**、不跳版 |
| 图片失败 | 把 `public/photos/thumb/P0001.webp` 改名 | 色块 + 极小的 ID，无破图图标 |
| 空结果 | `/gallery?f=detail` 且该分类为 0 张 | 一行"这一类还没有照片"+"看全部" |
| 单张 | 筛选到只有 1 张 | 不显示 "1 / 1"、不显示翻页 |
| 超长描述 | 临时把某张 description 改成一整段 | 底栏一行省略，不撑破布局 |
| 无描述 | 清掉某张的 description | 该行整行不出现，不留空行 |
| 无时间 | 某张 time 置 null | 时间位置不留孤立分隔符 |

## 5. 性能走查（打开 DevTools Network）

- [ ] 首页首次加载（Clear 后刷新）：**传输总量 < 1MB**
- [ ] 首屏大图有 `fetchpriority="high"`，且**只预加载一张**
- [ ] 打开 Gallery：**不加载任何 preview 图**（过滤 `/photos/preview/` 应为 0 个请求）
- [ ] 滚动 Gallery：缩略图是**滚动到附近才请求**，不是一次性全部
- [ ] 打开大图后：才出现 1 个 preview 请求
- [ ] Lighthouse：LCP < 2.5s、**CLS < 0.02**、无长任务警告
- [ ] 把 CPU 降速 4×，滚动仍然不卡（瀑布流没有 JS 布局计算）

## 6. 可达性与减弱动态效果

- [ ] 只用键盘：Tab 能走完导航 → 筛选 → 模式 → 照片 → 打开 → 翻页 → 关闭
- [ ] 焦点圈始终可见（细的 accent 色描边，不是浏览器默认蓝框）
- [ ] 系统开启「减弱动态效果」后：所有位移与淡入消失，**内容依然完整可见**
- [ ] 正文对比度 ≥ 4.5:1
- [ ] 每个可点元素都是 `button` 或 `a`

## 7. 视觉终审（最后一步）

对着 `docs/02-UI设计契约.md` 的反模式清单逐条排除：

- [ ] 没有"卡片 + 阴影 + 胶囊标签"三件套
- [ ] 没有渐变、发光、玻璃拟态（导航栏的轻微模糊是唯一例外）
- [ ] 没有图标（相机、爱心、日历…）
- [ ] 没有轮播图、没有飘落花瓣、没有满屏粒子
- [ ] 不是每个元素都做入场动画
- [ ] 截图发给一个不知情的人，他**不会**说"这是婚庆公司网站"

最后问自己三个问题（来自计划书 §19 的内容验收）：

1. 第一次访问，我明白那天发生了什么吗？
2. 第二次访问，我能快速找到某张照片吗？
3. 很多年以后再打开，我还能想起这一天吗？

~~~text
页 面：/gallery（375px，iPhone 微信内置浏览器）
现 象：滚动到第 3 屏时，右侧出现一条 1px 的横向滚动条
期 望：没有横向滚动条
严重度：中（影响观感，不影响功能）
复 现：打开 /gallery → 滚动到 1200px 处
~~~
